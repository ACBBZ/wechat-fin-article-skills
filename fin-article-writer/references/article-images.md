# 第 8 步：正文真实配图与原创信息图

正文配图的任务不是装饰，而是增加现场感、证据感、历史纵深和机制理解。封面不计入正文配图数量。

## 目录

- 数量与固定位置
- 四类配图角色
- 至少两张图的补足规则
- 图片搜索顺序
- 权利状态
- 格式转换
- 语义锚点与文章结构
- 第一个、第二个有判断感的小标题
- 图注
- 资产记录

## 数量与固定位置

- **最终正文至少 2 张配图，通常 2–4 张。**
- 所有最终正文图片统一保存为 **`.png`**，不在发布稿中使用 `.jpg`、`.jpeg`、`.webp` 作为正文图片文件。
- **第一张必需图片紧邻第一个 `##` 小标题之前。**
- **第二张必需图片紧邻第二个 `##` 小标题之前。**
- 这两张图分别承担两个主要段落的语义锚点。即使增加第 3、4 张图，也不能把这两个固定位置挪走。

推荐文件名：

```text
output/images/01-before-subtitle-1.png
output/images/02-before-subtitle-2.png
output/images/03-extra.png
output/images/04-extra.png
```

## 四类配图角色

### 当前事件图

用于证明“这件事正在发生”。可以是事件现场、机构公开照片、产品或业务现场。必须和正文正在讨论的事件直接对应，不能用泛化的大楼照片凑数。

### 原始证据图

优先级很高。包括交易所公告关键页、监管文件、公司公告、基金公告、财报、招股书、官方数据页面。可以合理裁切空白、框选重点，但不能修改原始文字或制造误导性上下文。

### 历史新闻图

只从已经通过历史相关度闸门并实际进入正文的案例中寻找。必须核对事件、日期、主体和图注，不能用“看起来差不多”的另一次事件替代。

### 解释性数据图

当真实照片不足以解释问题，优先用已核实数据生成原创图，例如价格与净值、溢价率、成交额、规模、政策时间线、机制流程图。所有数值和口径必须来自第 1、5 步已经核实的来源。

## 至少两张图的补足规则

真实新闻图只有在来源、事件匹配和使用条件都清楚时才能自动插入。如果最终能自动使用的真实新闻图少于 2 张：

1. 不得用版权不明的媒体摄影、搜索缩略图或二手截图凑数；
2. 优先生成原创数据图、时间线图或机制图；
3. 原创图必须基于已核实事实或数据，不能把推测画成事实；
4. 最终必须形成至少 2 张 `AUTO_INSERT` 的 PNG 图片，分别放在两个 `##` 小标题之前。

## 图片搜索顺序

每张图按以下顺序寻找：

1. 正文事实对应的原始来源；
2. 原始页面是否有可用图片、公告或图表；
3. 官方机构、公司、基金公司是否有公开材料；
4. 权威媒体是否有高度相关的历史新闻图；
5. 搜索引擎只用于发现，必须回到原网页核实。

先找事件，再找图。搜索结果缩略图不是可发布资产。

## 权利状态

### 可自动插入（`AUTO_INSERT`）

满足使用条件并能追溯来源的官方公开材料、用户明确拥有使用权的图片、开放许可或公共领域图片、以及 Agent 基于已核实数据自行生成的原创图。最终文件统一为 PNG。

### 仅作为候选（`CANDIDATE_ONLY`）

新闻媒体摄影图、商业图库、带明确媒体版权标识但无法确认转载许可的图片、权利状态不清楚的现场图。可以记录候选信息，但不进入 `article.md`。

### 拒绝使用（`REJECT`）

来源不明、时间无法确认、二次搬运、抹水印、事件不匹配、AI 图冒充新闻现场、无法追溯原网页的搜索缩略图。

## 格式转换

最终正文只引用 PNG。如果一个已经确认可使用的源图片是其他格式，可以做无事实改变的格式转换后保存为 PNG；**格式转换不会改变版权状态**。不得通过裁水印、镜像、改色等方式“洗图”。

## 语义锚点与文章结构

最终 `article.md` 必须满足下面的基本位置结构：

```markdown
开篇正文……

![配图1](images/01-before-subtitle-1.png)

*图：……来源：……*

## 第一个有判断感的小标题

正文……

![配图2](images/02-before-subtitle-2.png)

*图：……来源：……*

## 第二个有判断感的小标题

正文……
```

图片应出现在读者刚产生“真的假的”“过去是什么样”“这个机制怎么运行”的位置。两张必需图片固定在两个小标题之前，其余图片再按语义插入。

## 图注

每张最终图片都必须有图注，至少说明“这是什么 + 为什么与正文有关 + 来源”。原创数据图写明“数据来源”和“本账号整理/绘制”。不要写“从图中可以清晰看到”这类空话。
