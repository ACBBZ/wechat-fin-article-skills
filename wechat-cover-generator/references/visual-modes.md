# 封面视觉模式

支持 `general` 与 `emotion_meme` 两种语义模式，`auto` 负责自动路由。模式决定情绪强度和构图纪律，`references/gpt-image2-style-routing.md` 再决定 category / style / scene / template。

## 共同规则

- 一个核心视觉概念优先于多个信息点。
- 核心主体必须足够大，小尺寸缩略图仍能一眼识别。
- 横版构图成立，同时中央 1:1 方形裁切不伤主体。
- 事实状态不能被视觉夸大。
- 背景服务主体，不做复杂信息堆叠。
- 不依赖细小文字解释画面。
- 每次模式选择后都必须继续生成 `style_reference`，不能把模式本身当成最终风格。

## 自动路由

### `general`

适合政策制度、宏观分析、产业趋势、公司深度、严肃商业事件。默认路由到克制的 poster / realistic / commerce 类方向；若文章核心更适合抽象解释，也可以选择 illustration，但不能把概念视觉伪装成真实照片。

### `emotion_meme`

适合暴涨暴跌、市场失控、投资者焦虑、公司暴雷、巨额盈亏、强烈反差或荒诞财经情境。默认仍使用有版式纪律的 poster 路由，只把主体情绪、动作和视觉隐喻放大。

如果文章涉及伤亡、重大灾害、严重违法受害者等不适合娱乐化的内容，强制回到 `general`。

## 通用模式

核心公式：

> 单一强主体 + 清楚财经语义 + 简单背景 + 高辨识色彩 + 可选极少量文字

特点：

- 主体居中或中央偏移，保证方形裁切；
- 可以用机构、产品、物体、人物或抽象机制作为主体；
- 色彩对比明确，但不追求无意义的高饱和；
- 文字如出现，必须短、少、可读，不能重复完整标题；
- 优先匹配 `poster-layout-system` 或其他适合封面的 upstream 模板方向。

## 强情绪模式

核心公式：

> 1 个强主体 + 1 个夸张动作或情绪 + 1 个财经隐喻 + 1 个高对比视觉锚点 + 极简背景 + 默认无文字

### 主体

主体通常占画面约 65%–90%。优先人物、动物、拟人物体或一个非常明确的财经场景。

### 情绪

情绪必须一眼可辨，例如惊、慌、兴奋、失控或强烈反差。情绪服务文章，不凭空制造恐慌。

### 隐喻

常见转译方式：

- 上涨：向上冲、升空、被抛起；
- 下跌：坠落、滑落、失去支撑；
- 赚钱：财富被抱住、流入；
- 风险：裂缝、悬崖、警示灯、失去平衡；
- 套牢：被夹住、缠住、困住；
- 流动性：通道变窄、流体受阻；
- 杠杆：支点、长杆、失衡结构。

隐喻必须符合 `factual_constraints`。文章只说“可能上涨”时，不能画成必然冲天。

## 文字策略

- `general`：可以 `allow_minimal`，但优先让图本身成立；
- `emotion_meme`：默认 `no_text`；
- 用户明确要求文字时，仍要确保文字准确、短、可读，不制造文章没有的事实。

## 不使用的视觉

- 多主体群像、复杂小元素、密集信息图；
- 与正文没有信息关系的交易所大楼、美元符号、K 线背景等“财经装饰”；
- 历史事件冒充当前事件；
- AI 生成的人物或场景冒充真实新闻现场；
- 需要读很小的字才能理解的画面；
- 直接复刻上游案例或具体创作者的独特风格。
